# dinoisland
Dinosaur Island — Facebook Engineering Puzzle solution

2009: Some of the most fun I've ever had coding.  I gave my dinosaurs a hive mind, so they could share map information with each other.  I created a lot of tunable variables and then had it auto run on repeat, adjusting the variables and recording the results, so I could regress to find optimal values/combinations.  I developed a GUI view of the map, and my next step was going to be to give myself the ability to steer the dinosaurs in real time (Warcraft style).  Unfortunately, at this point the puzzle server crashed (repeatedly).  I have worried that perhaps using a hive mind was cheating, and I had overwhelmed the servers.  However, I recently found [An unofficial guide to the Facebook Engineering Puzzles](https://www.davideisenstat.com/fbpfaq/) which says "The highest-scoring species are hive minds that overcome the limited vision of individual dinosaurs."  That finally put my mind at ease after 15+ years, but I am curious how [David Eisenstat](https://www.davideisenstat.com/) would know this, unless he was the mysterious Puzzle Master?  [TechCrunch](https://techcrunch.com/2010/03/24/longtime-facebook-engineer-yishan-wong-departs/) has described [Yishan Wong](https://x.com/yishan) as "the original author of Facebook Puzzles" so who knows...
